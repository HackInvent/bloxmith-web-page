Sources are stored in the blueprint. JavaScript runs in the browser only.

The URL carries the project, the blueprint, the instance and the block's unique identifier.

Example: {"view":"complete"}. The parameters do not change the graph.

In the HTML: @inputs.in, @inputs.in.title, @query.view.
To display a reference without substituting it: @@inputs.in.title.
In the JavaScript: bloxPage.data.inputs et bloxPage.query.
An update reloads the isolated page. No network, cookie or application API access from your code.

Add and name the inputs through the block's Ports context menu. Every name is available in inputs.
