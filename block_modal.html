Sources enregistrees dans le blueprint. JavaScript execute dans le navigateur uniquement.

L'URL inclut le projet, le blueprint, l'instance et l'identifiant unique du bloc.

Ouvrir la page enregistree

Exemple : {"view":"complete"}. Les parametres ne modifient pas le graphe.

Dans le HTML : @inputs.in, @inputs.in.title, @query.view.
Pour afficher une reference sans la remplacer : @@inputs.in.title.
Dans le JavaScript : bloxPage.data.inputs et bloxPage.query.
Une mise a jour recharge la page isolee. Aucun acces reseau, cookie ou API de l'application depuis votre code.

Ajoutez et nommez les entrees via le menu contextuel Ports du bloc. Chaque nom est disponible dans inputs.
